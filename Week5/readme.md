# Student Management Front End

<img width="1795" height="751" alt="image" src="https://github.com/user-attachments/assets/c4fce512-9991-4e8f-987f-a2f97ea120cf" />


Praktik membuat tampilan Front end CSS, melalui implementasi ini mengetahui hubungan antara HTML sebagai struktur dan CSS sebagai pengatur layout, visual, komponen, serta responsive design.

--
## Fitur
- Menambahkan data mahasiswa
- Mengedit dan menghapus data
- Mencari data mahasiswa
- Pagination
- Responsive layout

## Teknologi
- HTML
- CSS
- JavaScript

## Struktur File
```

└── script.js
```
