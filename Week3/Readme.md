# Website SMAIT Ihsanul Fikri Mungkid

Website sederhana untuk SMAIT Ihsanul Fikri Mungkid yang dibuat sebagai tugas Pemrograman Web.

## Fitur

- Halaman Home
- Sambutan Kepala Sekolah
- Informasi sekolah
- Visi dan Misi
- Informasi jurusan
- Tabel jumlah siswa
- Halaman kontak
- Form kontak
- Responsive navigation untuk tampilan mobile

## Teknologi

- HTML5
- CSS3
- JavaScript
