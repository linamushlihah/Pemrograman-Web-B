## Fitur

- Halaman Home
- Sambutan Kepala Sekolah
- Informasi sekolah
- Visi dan Misi
- Informasi jurusan
- Tabel jumlah siswa
- Halaman kontak
- Form kontak
- Responsive navigation untuk tampilan mobile

## Teknologi

- HTML5
- CSS3
- JavaScript

# Penjelasan File
## 1. index.html

File index.html merupakan halaman utama atau Home dari website.

Di dalam file ini terdapat:

- Header dan navigation bar
- Logo sekolah
- Hero section
- Sambutan Kepala Sekolah
- Informasi singkat mengenai sekolah
- Bagian Visi dan Misi
- Footer

Halaman ini menjadi halaman pertama yang ditampilkan ketika website dibuka.

## 2. jurusan.html

File jurusan.html digunakan untuk menampilkan informasi mengenai jurusan yang tersedia di sekolah.

Halaman ini berisi beberapa card jurusan yang masing-masing memiliki:

- Nama jurusan
- Deskripsi singkat
- Informasi program

Selain itu, terdapat tabel yang menampilkan data jumlah siswa pada setiap jurusan.

## 3. kontak.html

File kontak.html merupakan halaman yang digunakan untuk menampilkan informasi kontak sekolah.

Halaman ini memiliki form yang terdiri dari:

- Input nama
- Input email
- Textarea untuk pesan
- Tombol kirim

Form digunakan sebagai simulasi fitur pengiriman pesan pada website.

## 4. style.css

File style.css digunakan untuk mengatur tampilan seluruh halaman website.

Beberapa bagian yang diatur menggunakan CSS antara lain:

- Warna dan tema website
- Font
- Navigation bar
- Hero section
- Layout dan spacing
- Card jurusan
- Tabel
- Form kontak
- Button
- Footer
- Responsive layout

CSS juga menggunakan media query untuk menyesuaikan tampilan website pada perangkat dengan ukuran layar yang lebih kecil.

## 5. script.js

File script.js digunakan untuk menambahkan interaksi pada website.

Fungsi utama JavaScript pada website ini meliputi:

- Membuka dan menutup menu navigasi pada tampilan mobile.
- Mengatur perpindahan tab pada bagian Visi dan Misi.
- Menangani interaksi pada form kontak.
- Menampilkan notifikasi ketika form dikirim.

JavaScript membuat website tidak hanya bersifat statis, tetapi memiliki beberapa interaksi yang dapat dilakukan oleh pengguna.

## 6. Folder image/

Folder image/ digunakan untuk menyimpan seluruh gambar yang digunakan pada website.

Isi folder terdiri dari:

- logo.png : logo SMAIT Ihsanul Fikri.
- kepala-sekolah.jpg : foto kepala sekolah.
- sekolah.jpg : foto bangunan sekolah yang digunakan pada bagian hero.
- sekolah-aerial.jpg : foto sekolah dari tampilan udara yang digunakan pada bagian informasi sekolah.

Gambar dipanggil dari HTML dan CSS menggunakan relative path dari folder image.
